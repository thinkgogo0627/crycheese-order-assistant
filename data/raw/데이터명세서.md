# 주제1 데이터명세서

- 주제: 식자재 관리 및 발주 자동화
- 기간: 2026-01-01 ~ 2026-09-30 (273일)
- 매장: 3개 (가상매장 A, B, C)

## 1. 이 데이터는 무엇인가요

크라이치즈버거 원본 데이터(POS 판매, 발주·입고 이력)에서 비율, 패턴, 분포만 추출해 새로 생성한 합성 데이터입니다. 원본 파일과 실제 수치는 크라이치즈버거 내부에서만 처리했고, 이 데이터셋에는 실제 매장명, 공급업체명, 매출액, 매입 단가, 개별 거래 기록이 포함되어 있지 않습니다.

- 판매량의 절대 규모는 가상으로 설정했습니다. 매장 간 상대 규모, 요일·월·시간대 패턴, 메뉴 구성비는 원본 특성을 반영했습니다.
- 모든 금액(판매가, 매입 단가, 발주금액, 재고금액, 폐기비용)은 원본과 무관한 가상 가격 체계입니다.
- 합성 데이터에서 얻은 모델 성능이나 비용 절감 효과는 실제 매장 성과로 주장할 수 없습니다.

## 2. 데이터 연결 관계

```
09_sales (메뉴 판매량)
  → 04_bom (메뉴별 식자재 사용량)
  → 10_inventory_daily (식자재 소진·재고)
  → 11_purchase_orders (발주) → 12_receipts (입고)
  → 06_ingredient_price_history (가상 단가) → 비용 분석
```

### 10_inventory_daily.csv
| 컬럼 | 설명 |
| --- | --- |
| opening_qty | 기초재고 (전일 기말재고와 같음, 07시 입고 전) |
| received_qty | 당일 07시 입고량 (전날 정기발주분 + 전날 긴급발주분) |
| adjust_qty | 영업 전 재고 실사 조정량 (+/−) |
| counted_qty | 영업 전 실사 수량 (= 기초 + 입고 + 실사조정) |
| consumed_qty | 판매에 따른 소진량 (= 판매 확정 수량 × BOM) |
| waste_qty | 폐기량 |
| transfer_in_qty, transfer_out_qty | 매장 간 이동 입고·출고량 |
| closing_qty | 기말재고 |
| closing_value | 기말재고 금액 (가상 단가 기준) |
| stockout_flag | 그날 이 식자재가 떨어져 판매가 막혔으면 1 |
| emergency_flag | 당일 긴급발주 발생 여부 |
| avg_consumption_7d | 당일 포함 최근 7일 소진량 평균 (소수 둘째 자리) |
| low_stock_flag | avg_consumption_7d > 0 이고 기말재고 < avg_consumption_7d |
| overstock_flag | avg_consumption_7d > 0 이면 기말재고 > 7 × avg_consumption_7d, 0이면 기말재고 > 0 |

이 재고 파일의 입고·소진·폐기·이동·재고 수량은 use_unit 기준 정수입니다. 개·매·캔·장은 개수, g·ml은 1단위이며, 평균 소진량은 소수일 수 있습니다. 재고 수지 계산은 이 파일을 기준으로 합니다.

| 품절 | 가정 | 실제로 품절이 생기고 슬랙으로 보고하는 운영을 반영, 발생 빈도는 시뮬레이션 결과 |
| 재고 실사 | 원본 반영 | 매일 영업 전 실사, 장부 차이 발생 확률·크기는 가정 |
| 매장 간 이동, 긴급발주 | 가정 | 재고 부족 시 이동 먼저, 그래도 부족하면 품절 처리 후 긴급발주 (다음날 입고) |
| 상권 유형, 매장 형태 | 가정 | 분석 편의를 위한 설정 |

## 6. 수량·시점과 운영 규칙

- 모든 CSV는 `data/`에 있습니다. 날짜는 YYYY-MM-DD, 금액은 가상 원화 금액입니다.
- `qty = demand_qty - lost_qty`, 판매 확정 수량은 `qty - cancel_qty`입니다. 식자재 소진량은 판매 확정 수량에 해당 메뉴 BOM을 곱해 합산합니다.
- 세트는 세트 메뉴의 BOM을 직접 사용합니다. `set_components`를 펼쳐 추가 합산하지 않습니다. 단품 합계와 세트 BOM이 같다고 가정하지 마세요.
- `promo_flag`는 매장·행사 기간 표시이며 모든 표시 행이 할인 대상 메뉴라는 뜻은 아닙니다. 대상은 `08_promotions.csv`를 확인하세요.
- 단가는 품목별로 발주일 이하인 `valid_from` 중 가장 최근 값을 적용합니다. `unit_price`는 발주단위당 금액입니다.
- 기말재고 = 기초재고 + 입고 + 실사조정 + 이동입고 - 이동출고 - 소진 - 폐기입니다. 실사재고는 기초재고 + 당일 입고 + 실사조정입니다.
- 미취급 기간, 품절에 따른 판매 손실, 취급 중 주문 없음은 구분해야 합니다. 세 매장은 전체 기간 영업하며 휴점·단축영업은 없습니다.
- 공급업체 A는 일~금 발주, 마감 17시, 다음날 입고, 최소금액 120,000원입니다. 공급업체 B는 일·화·목·금 발주, 마감 16시, 다음날 입고, 최소금액 제한이 없습니다. 세부 값은 05_suppliers.csv를 따릅니다.
- 발주는 품목별 order_unit의 정수 수량으로 하며 min_order_qty를 확인합니다.
- 합성 기록의 하루 처리 순서는 07시 입고 → 영업 전 실사 → 정기발주 판단 → 시간대별 판매·필요 시 이동·품절·긴급발주 → 마감 후 폐기 → 기말 확정입니다. 기록 시각과 판단 시점의 차이는 8절을 참고하세요.
- 입고는 07시이며 긴급발주도 다음날 입고됩니다. 긴급발주는 최소금액·요일·마감 제한의 예외입니다. 정기발주는 마감 정각을 포함하지 않으며 공휴일 별도 예외는 없습니다.
- 마지막 사용일 = 입고일 + 사용 가능 일수 - 1입니다. 마지막 사용일의 판매에 사용할 수 있고 마감 후 잔량을 폐기합니다.
- 사용기한이 빠른 묶음부터 사용하고, 같으면 입고일 순서로 사용합니다. 이동된 재고의 입고일과 사용기한은 유지합니다.
- 초기재고는 2025-12-31 입고로 설정한 첫 7일 평균 소요량의 3일분입니다. 실사 감소는 오래된 묶음부터 차감하고 증가는 가장 최근 입고 묶음에 더합니다.
- `16_inventory_lots_daily.csv`는 영업 종료 후 상태입니다. 당일 추천에 당일 기말 정보나 미래 판매를 사용하면 미래 정보가 포함됩니다.

## 7. 합성 발주 정책

아래는 제공된 과거 기록을 생성한 정책입니다. 참가자가 구현할 추천 알고리즘을 지정하는 규칙은 아닙니다. 실제 매장 담당자의 발주 결정을 그대로 재현한 산식도 아닙니다.

```text
매일, 공급사별로 (그날이 발주 가능 요일일 때만, 실사 이후)
  다음 발주일 = 오늘 이후 첫 발주 가능 요일
  커버 일수 = (다음 발주일 − 오늘) + 1
  품목별로
    f = 전일까지 최근 7일 실제 소진량 평균 (당일 제외, 데이터 시작 전 날짜는 빼고 평균)
        이력이 하루도 없으면 초기재고 ÷ 3
        품절이 있었던 날은 실제 소진량이 수요보다 작게 들어감
    현재 위치 = 실사 재고 − f + 입고 예정량 합계
    목표 = f × min(커버 일수, 소비기한일수) × (1 + 안전계수)
           안전계수: 냉동 0.25, 냉장 0.15, 상온 0.30
    f > 0 이고 현재 위치 < 목표이면
      발주량(포장단위) = 올림((목표 − 현재 위치) ÷ 포장단위당 수량)
      급함 = 현재 위치 < 2 × f
  발주서 금액 < 최소 발주금액이면
    급한 품목이 없으면 → 이번 발주 전체를 다음 발주일로 미룸
    급한 품목이 있으면 → 하루 소진량(포장단위 기준)이 큰 품목부터 1단위씩 돌아가며 추가해 최소금액을 맞춤

품절 시 긴급발주량 = 올림(f × 1.5 ÷ 포장단위당 수량), 최소 1단위
```

발주 정책의 평균은 당일을 제외한 과거 소진량입니다. 재고 파일의 `avg_consumption_7d`는 당일을 포함한 평균이므로 구분하세요. 최소금액 증량 대상의 범위는 생성 설명에 명시되어 있지 않습니다. 발주 대상으로 선정된 품목에만 증량하는 방식으로 계산하면 1,170개 매장·공급사·발주일 조합 중 1,168개가 재현되며, 두 경계 사례는 8절에 기재했습니다. 이 미확정 범위를 사용할 때는 적용 가정을 밝혀 주세요.

실사조정 발생은 품목별 15% 확률, 조정량은 재고에 평균 0·표준편차 1.2%인 정규분포 값을 곱한 뒤 반올림하는 합성 가정입니다. 냉장 품목의 품질 폐기는 마감 후 6% 확률로 잔량의 2~8%를 폐기하도록 설정했습니다. 이동은 제공 매장의 당일 남은 필요량과 평균 소진량 2일분을 남기는 생성 규칙을 사용했습니다. 이 규칙에는 실제 의사결정 시점에서 알기 어려운 당일 수요 정보가 포함될 수 있습니다.
