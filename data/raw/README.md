# 식자재 관리 및 발주 의사결정 지원 — 데이터 안내

2026-01-01~2026-09-30의 3개 매장·16개 메뉴·22개 식자재 자료입니다. 판매·재고·발주 이력은 합성 데이터이며 모든 금액은 가상 가격입니다. BOM의 구성과 개수는 실제 레시피를 참고하고 일부 사용량은 조정했습니다.

## 폴더 구성

```text
README.md          데이터 소개와 이용 안내
데이터명세서.md    파일·컬럼·연결·산식·운영 규칙과 알려진 한계
data/              CSV 17개
```

먼저 아래 파일 구성을 확인한 뒤, 사용하는 데이터의 정의와 단위를 `데이터명세서.md`에서 확인하세요. 필요한 기본 정보는 이 폴더 안에 포함되어 있습니다.

## 데이터 구성

- 01~08: 매장·메뉴·식자재·BOM·공급사·가격·달력·행사

## 사용 시 확인

- CSV는 UTF-8 인코딩이며 첫 행은 컬럼 이름입니다.
- 알려진 오류와 기준 차이는 명세서에 정리되어 있습니다. 사용하는 항목의 주의사항을 확인하세요.
- 전처리, 추가 가정, 직접 생성한 테스트 데이터는 제공 자료와 구분해 기록하세요.
- 합성 데이터에서 얻은 성능·절감액·개선 효과를 실제 매장 성과로 해석하지 마세요.
