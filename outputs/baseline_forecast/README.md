# 팀 공통 기본 수요 예측

현재 예측을 공통 기준으로 두고 팀원이 각자 개선하기 위한 **모델 학습·선택·예측 코드**입니다. 발주 최적화와 재고·폐기 시뮬레이션은 포함하지 않습니다. 예측 계산은 기존 첫 실험과 동일합니다.

## 실행

Python 3.12 환경에서 저장소 루트 기준으로 실행합니다.

```sh
python -m pip install -r outputs/baseline_forecast/requirements.txt
python outputs/baseline_forecast/train.py
```

데이터는 `data/`를 먼저 확인하고 필요한 파일이 없으면 `data/raw/`를 확인합니다. 다른 위치라면 다음처럼 지정합니다.

```sh
python outputs/baseline_forecast/train.py --data-dir "원본 CSV 폴더" --output-dir outputs/baseline_forecast/artifacts
```

노트북으로 보려면 `01_train_baseline.ipynb`를 열고 위 패키지를 설치한 Python 커널을 선택합니다. 원래 작업 PC에서는 `.venv-notebook/Scripts/python.exe`를 사용합니다. GitHub 노트북은 출력 없이 공유하며 실행하면 점수와 선택 모델을 볼 수 있습니다.

필요한 제공 CSV는 `01_stores`, `02_menus`, `07_calendar`, `08_promotions`, `09_sales`, `15_menu_availability`입니다. 파일명은 제공된 `번호_이름.csv`를 유지하세요. 원본 데이터는 이 변경에 포함하지 않습니다. 제공 자료 이용 조건에 따라 별도로 관리하세요.

## 기본 모델

매장마다 별도 학습하며 한 매장 내16개 메뉴를 함께 학습합니다. 목표는 일별 `demand_qty`(품절 전 잠재 수요)입니다. 원자료는2026년1~9월,3개 매장·16개 메뉴의 고정 구조입니다. 다른 기간/매장/메뉴 자료를 그대로 넣는 일반 목적 도구는 아닙니다.

|후보|설명|
|---|---|
|mean7|최근7일의 취급일 평균|
|weekday4|최근28일 중 같은 요일의 취급일 평균|
|blend|위 두 예측의50:50혼합|
|hgb_own|Poisson 손실 HistGradientBoosting, 자체 과거 수요와 달력/메뉴 피처|
|hgb_cross|자체 피처+전체16개 메뉴 전일/직전7일 수요|

기본 선택 결과는 **S01 blend, S02 mean7, S03 mean7**입니다. ML 후보도 비교 대상으로 학습·저장하지만 강제로 채택하지 않습니다. 모델 하이퍼파라미터와 피처 순서는 `train.py`에서 확인할 수 있습니다.

## 기간과 정보 경계

- 1~6월 학습 → 7월 h=0~3 WAPE로 매장별 선택 → 7월까지 재학습 → 8~9월 고정 평가.
- h=0은 영업 전 오늘, h=1은 내일. h=0~13을 직접 예측합니다. 학습 정답 날짜는 각 학습 종료일을 넘지 않습니다.
- 8~9월에도 최근 수요 입력은 매일 전일까지 갱신합니다. 6월 수요 수준을 고정하는 방식이 아닙니다. ML 가중치는7월까지 재학습한 뒤 고정합니다.
- 메뉴 취급과 행사 계획이 사전에 알려졌다고 가정합니다. 실제 공지 시점은 없습니다. 데이터 종료 후 짧은 전망은 마지막 취급 상태 유지/추가 행사 없음으로 처리합니다.
- 과거 잠재 수요가 관측 가능하다는 합성 데이터의 조건입니다. 실제 매장의 품절에 가려진 수요 추정은 별도 과제입니다.
- 신규 메뉴는 과거 동일 분류 수요로 대체합니다. 모든 결과의 의미가 달라지므로 개선 시 이 처리도 기록하세요.

## 생성 파일과 팀원 개선

기본 출력은 이 폴더의 `artifacts/`이며 Git에서 제외합니다.

- `models/`: 매장별·평가 단계별 ML 모델12개. 평균 방식은 코드를 통해 계산합니다.
- `model_selection.json`, `model_manifest.json`: 선택 모델·피처·학습 경계·가정·입력 해시.
- `forecast_scores.csv`: 매장/모델/평가기간별 WAPE·MAE·bias.
- `daily_menu_predictions.csv`: 매장·메뉴·날짜별 당일 예측과 평가용 실제 수요.
- `forecasts_validation.npz`, `forecasts_test.npz`: 예측일×horizon×매장×메뉴 배열. shape=(273,14,3,16), 매장S01~S03/메뉴M001~M016 순서. 해당 평가기간 밖의 origin은0으로 채운 미계산 구간입니다. `selected` 키로 공통 기본 예측을 가져옵니다.

개선할 때는 각자 브랜치에서 피처/학습 구간/모델을 변경하고 같은 지표와 시간 경계를 유지해 비교하세요. 출력 폴더를 따로 지정하면 기준 결과를 덮어쓰지 않을 수 있습니다.

모든 달 수요가 동질적임을 확인한 실험이 아닙니다. 월별로 학습·선택·평가 시점을 옮기는 반복 검증과 최근 기간만 학습하는 방법 비교가 후속 과제입니다. 전체 기간을 이미 탐색했으므로 이를 완전한 미관측 성능으로 주장하지 않습니다. 예측 정확도만으로 부족·폐기 감소를 확정하지 않습니다.

합성 데이터의 기준 모델이며 실제 매장 성과를 의미하지 않습니다. 원본·개별 예측 결과·학습 가중치·실행 출력이 담긴 노트북은 이번 코드 공유에서 제외합니다.
